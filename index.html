⚙️ Playing Week Settings

Controls the "This Week" card and weekly achievement badges for every player.
Saving starts a brand new cycle immediately using the new length. Lifetime profit/loss, the net-balance chart, and every player's activity calendar are never affected — only the "This Week" card and this week's achievement badges reset.
Makes the current week longer without ending or resetting it. Every match so far stays in the week, the weekly graph and badges keep counting, and the week just finishes later. Players see the new end date straight away.
Adding days needs one extra one-time step: run alter table app_settings add column if not exists week_overrides jsonb not null default '[]'::jsonb; in your Supabase SQL Editor.
Ends the current week immediately — without waiting for it to run its course — and starts a fresh one today, keeping the same week length. Use this if the club's schedule changes mid-week. Same safety guarantee: lifetime totals and the activity calendar are untouched, only "This Week" and this week's achievements reset.
Cancels all confirmed transactions and match requests for the current playing week, bringing everyone's weekly net to zero. Past weeks and lifetime history are untouched, and the week keeps running.
This feature needs one extra one-time step: run the app_settings SQL block from the setup instructions in your Supabase SQL Editor. Until then, this setting can't be saved or shared across devices.
